# Mechabot STEAM Academy Website

Trang giới thiệu học viện Robotics &amp; AIoT Mechabot, dạng nhiều trang (mỗi mục menu là một trang riêng):

- `index.html` - Trang chủ (hero, teaser giới thiệu, teaser chương trình, đối tác, cảm nhận phụ huynh).
- `about.html` - Giới thiệu (về MechaBot, vì sao chọn MechaBot, đội ngũ giảng viên).
- `programs.html` - Chương trình đào tạo (chi tiết các khóa học theo độ tuổi).
- `maker-space.html` - Maker Space (phòng lab, cơ sở vật chất).
- `projects.html` - Dự án học sinh (portfolio, lọc theo danh mục).
- `library.html` - Thư viện &amp; tin tức.
- `faq.html` - Hỏi đáp.
- `contact.html` - Liên hệ.
- `styles.css` - giao diện responsive, hiệu ứng reveal khi cuộn.
- `script.js` - menu di động, lọc thư viện dự án, accordion FAQ, hiệu ứng cuộn.

Mỗi trang dùng chung header, footer và banner "Đăng ký học thử" (`#booking`); nút "Đăng ký học thử" trên header luôn cuộn tới banner này ở cuối trang hiện tại.

## Cách chạy

Mở `index.html` trong trình duyệt hoặc dùng một server tĩnh như `python3 -m http.server`.
